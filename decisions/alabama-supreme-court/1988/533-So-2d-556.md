# Stidham v. Marie McConnell Realty Co.

## Majority (PER CURIAM.)

PER CURIAM.
Because the plaintiff’s complaint does not state any allegations on which relief can be granted, the trial court properly dismissed the action pursuant to Rule 12, A.R.Civ.P. We affirm.
AFFIRMED.
TORBERT, C.J., and JONES, SHORES, ADAMS and STEAGALL, JJ., concur.
