# McLendon v. Mills

## Majority (BOLIN, Justice.)

BOLIN, Justice.
WRIT QUASHED. NO OPINION.
MOORE, C.J., and MAIN and BRYAN, JJ., concur.
MURDOCK, J., concurs specially.

## Concurrence (MURDOCK, Justice)

MURDOCK, Justice
(concurring specially).
I concur in quashing the writ in this case. I write separately to note that I would be open, in an appropriate case, to reexamining the issue whether the standard set out in Ex parts McLendon, 455 So.2d 863 (Ala. 1984), rather than the standard set out in Ex parte Couch, 521 So.2d 987 (Ala. 1988), should be applied to a petition to modify custody where joint physical custody has been maintained for a meaningful period pursuant to a prior court order.
