# Hubbard v. State

## Majority (PER CURIAM.)

PER CURIAM.
The petition for writ of certiorari is denied because the petitioner fails to suggest the likelihood of any reviewable issue if the out-of-time appeal sought by the, petitioner were allowed.
PETITION DENIED.
