# State v. McNair

## Majority (HOUSTON, Justice.)

HOUSTON, Justice.
After this Court ordered that the respondent file an answer and brief, the trial court granted the relief requested in the petition. The petition is moot; therefore, it is dismissed.
PETITION DISMISSED.
HORNSBY, C.J., and JONES, SHORES and KENNEDY, JJ., concur.
